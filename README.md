# СИБСВЯЗЬ — Пейджер

Интерактивный внутриигровой веб-пейджер для проекта **СИБСВЯЗЬ**.

## Возможности
- адаптивный интерфейс для телефона и компьютера;
- список входящих сообщений и непрочитанные сообщения;
- чтение сообщений, даты и время;
- управление экранными кнопками, мышью, касанием и клавиатурой;
- стилизация под монохромный алфавитно-цифровой пейджер;
- демонстрационное меню устройства.

## Управление
На компьютере: стрелки вверх/вниз, Enter, Escape. На телефоне: кнопки на корпусе и касание сообщения.

## Сюжетные данные
Сообщения находятся в массиве `messages` в `app.js`. Их можно менять без изменения HTML/CSS.

Проект статический и подходит для публикации через GitHub Pages.
